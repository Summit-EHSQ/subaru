*************************************************
Install Released Application Supplier Relationship Management 1.3.0

Install Released Application Quality Comply Solution	1.0.0

INSTALLATION INSTRUCTIONS
*************************************************
Install Checklist Framework(v1.0.0).ipack
Install APQP & PPAP Manager(v1.0.0.0).ipack
Install Checklist Framework - Data(v1.0.0).ipack
Install APQP & PPAP Manager - Data(v1.0.0.0).ipack

Views Add-On (Mandatory)
For clients with Platform version 6.5.75 or higher install package Views Add-on(v1.0.0.0).ipack (ILX-8580)
