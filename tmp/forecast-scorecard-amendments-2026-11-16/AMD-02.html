Task category:
Catalogue configuration

Objective:
Establish the three dedicated security groups and give them the approved catalogue read and maintenance permissions.

Detailed scope:
Create or reuse exactly one native Group for each of these names: Supplier Scorecard App - Supplier User Security Group; Supplier Scorecard App - Viewers Security Group; Supplier Scorecard App - Application Admin Security Group. Give all three View via Rights on the thirteen concrete scorecard catalogues. Give the Application Admin group View/Create/Edit/Delete on Supplier Commodity, NAICS Classification and KPI Category subject to existing protections, and reserve maintenance of the ten technical catalogues for Administrators. Apply the maintainer rules to inherited and directly declared editable fields and preserve supported lookup and historical references. Repeating setup must not duplicate Groups or repurpose a general Supplier User group.

Deliverable:
Three exact named native Group records, thirteen-catalogue View Rights, and the three-business/ten-technical catalogue maintenance permissions.

Work needed first:
CFG-03

What the earlier tasks provide:
CFG-03: Configured catalogue fields, forms, filters, audit, and permissions.

The exact Group names and grants are decided, so Group creation/reuse and the twelve available catalogue assignments can proceed without a new naming decision. Only Generation Lag Time Increment Rights and maintenance wait for its object/form from the separate scheduling amendment; membership administration remains outside this task.

How to check the result:

• Exactly one verified Group is used for each approved exact name; repeating setup creates no duplicate or changes to a general Supplier User group.

• A user belonging only to Supplier Scorecard App - Supplier User Security Group can read all thirteen concrete catalogues via Rights and receives no catalogue Create, Edit or Delete permission.

• A user belonging only to Supplier Scorecard App - Viewers Security Group can read all thirteen concrete catalogues via Rights and cannot maintain them.

• A user belonging only to Supplier Scorecard App - Application Admin Security Group can read all thirteen catalogues and maintain Supplier Commodity, NAICS Classification and KPI Category subject to lifecycle protections.

• The Application Admin user cannot maintain any of the ten technical catalogues through forms, direct URLs, APIs or import/update paths; Administrators can maintain supported technical records subject to the existing locks.

• Catalogue lookup adds no application/tab Use, inherited fields remain inherited, and inactive historical references remain readable.
