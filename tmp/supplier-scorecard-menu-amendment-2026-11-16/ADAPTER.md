# Draft amendment adapter

This is a draft validation adapter for a four-task amendment. It supplements rather than replaces the original 35-task build scope. The source plan and specification have not been modified by this draft. Original task IDs remain authoritative; IMP IDs are validator aliases only. No tenant implementation or verification is claimed.

The complete original source text and 35 original task records are preserved in implementation-plan.json under adapter.sourceText and adapter.baselineTaskRecords and in baseline-implementation-plan.md. The original-to-validator map is explicit and reversible. No main task is renamed. The four amended snapshots retain original scope and add configuration details; 31 unreviewed tasks retain their initial adapted hashes. The full rendered adapter supports graph/schema checks. amendment-proposal.md contains the four addenda for human review.

The task-content gate scope is IMP-01, IMP-03, IMP-26, IMP-27. A pass for those four records does not certify the 31 imported records or live tenant behavior. Both bundled gates must pass before delivery.

Validation completed: the structural gate passed for 35 tasks and 52 coverage records. The content gate passed for the four amended task snapshots and 77 manually reviewed operative units; 31 imported task snapshots remain explicitly unreviewed and frozen. The 24 menu paths match the approved specification in order, and the human amendment uses original task IDs. The source plan and specification are unchanged.
