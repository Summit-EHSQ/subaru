# Subaru brand application notes

This directory is an independent visual copy of `sites/supplier-quality-command-center`. The source command center remains the Intelex base-brand version.

## Standards applied

- Subaru Blue (PMS 280) is represented on screen as `#012169` and is the only brand-blue treatment.
- White and restrained neutral-gray surfaces follow the guide's document examples and permitted logo-background guidance.
- Headings, navigation emphasis, links, and primary actions use Subaru Blue.
- Typography uses a compact Arial/Helvetica system aligned with the guide's visual character.
- The command-center interpretation uses a deep navy hierarchy, bold action states, an electric-blue operational accent, and a custom photographic manufacturing hero while retaining Subaru Blue as the anchor brand color.
- Status colors remain semantic and are not presented as Subaru brand colors.

## Bold command-center interpretation

The second visual pass deliberately goes beyond the guide's restrained print examples while preserving its explicit mark rules. Headers and primary calls to action use dark navy for stronger hierarchy; cards use crisp white surfaces and architectural blue edge treatments; and the fixed navigation becomes a dark command bar.

The home-page hero image is an original, logo-free generated asset showing automotive component inspection in a modern manufacturing environment. It contains no Subaru marks, text, badges, vehicle identifiers, or third-party stock imagery. The asset is stored at `dist/assets/subaru-command-center-hero-v2.png`.

## Logo constraint

No Subaru logo has been recreated, traced, extracted, or altered. The guide requires original approved artwork, proportional sizing, the registration mark, and an isolation area of at least half the star-cluster oval height on every side. If an approved digital logo asset is supplied later, it should be inserted without modification and with that clear space preserved.

## Out-of-scope marks

The Total Cost of Ownership, warranty, Industrial Power Products, and Powered By marks are not used because they do not represent a command-center function and the guide prohibits altering those marks.
